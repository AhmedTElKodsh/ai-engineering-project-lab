# Curriculum reference map and state ownership

The linked curriculum documents were inspected on 11 October 2026. Links are pinned to the inspected upstream revision; their code was not all executed. They are reference bridges for the workbench, not a second active course.

The only active route is `learning/route.json`. `learning/evidence.jsonl` is factual history; `learning/state.json` and root `LEARNING.md` are derived views. Previous J0, M1 and seven-project routes, the from-scratch clone route and the 11 October S0–S8 route are superseded for this project. Historical state is retained under `archive/source-state/`; no completed capability was inferred from it. The separate curriculum checkout keeps its own lesson-completion rules and remains unchanged by adoption here.

## Mapping policy

The table supplies **bounded project bridges**. Many lesson frontmatters list much broader prerequisites than the project task needs. Extracts are therefore explicitly focused study, not full completion and not a rewrite of the lessons' prerequisites.

Use four study labels:

- **Full:** satisfy the whole lesson contract, quiz, and artifact requirements.
- **Focused bridge:** cover the named mechanism for the project; record remaining depth.
- **Comparison:** inspect or run a reference only after learner implementation; no authorship credit.
- **Deferred:** keep the topic visible for later, with a reason.

A mapped lesson being useful does not automatically make it required in the authoritative route. Do not silently expand the existing manifest. In particular, the Phase 7 transformer capstone and Phase 10 complete pipeline have broad completion requirements; completing this custom small-model project does not close those lessons in full.

## Adoption and contributions

The user authorized consolidation and publication on 11 October 2026 and the RAG/agents-first revision on 15 October 2026. The workbench uses the confirmed ten-hour weekly pace and CPU-first hardware. Tutoring starts from the first unresolved gate and the carried-forward support note, then adapts to actual evidence. A focused curriculum bridge does not mark the entire upstream lesson complete.

Core-route stages learn each mechanism with an existing library or framework, with just enough theory to use it correctly; see the [library map](08-LIBRARY-MAP.md) and TOOLING.md. Plain-Python reimplementation, NumPy/PyTorch internals and the learner-written language model belong to the optional from-scratch track.
