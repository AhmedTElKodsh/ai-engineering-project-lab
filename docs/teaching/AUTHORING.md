# Teaching and exercise authoring

One lesson serves one observable capability, with inputs, learner-owned decisions, relevant failures and an artifact. Select a suitable profile: first experience, build, debug, conceptual decision, integration, evaluation or defense. Use a palette rather than compulsory headings: orient/inspect/predict/run/trace/modify/verify/explain/transfer.

Explain in progressive layers when needed: workable intuition, a concrete trace, precise mechanism, limitation, engineering consequence and recovery. Retain prose that does a distinct cognitive job; remove restated quotas of stories or analogies. Analogies need a stated limit and a return to the actual mechanism. Offer accessible text descriptions beside Mermaid/SVG diagrams.

Give an analogous worked example with different data, then let the learner attempt the owned problem. A serious attempt is code/artifact plus expected versus observed behavior and a stuck boundary; no arbitrary duration or failure count applies. Follow AGENTS.md's gradual-help rule. Supplied tricky fragments/full solutions are assistance, and independence requires a fresh variation later.

Keep acceptance tests next to learner-editable modules; tests must import that implementation, not their own hidden reference answer. Starter TODO failures are expected, while missing fixtures/imports/broken paths are curriculum defects. Separate support tests from learner behavior. Use deterministic offline fixtures, normal/negative/boundary cases, nonzero failure exits, safe temporary output and one meaningful mutation showing the guard matters. A conceptual decision uses a counterexample rather than invented code.

Freeze assessment/holdout material appropriately. Do not reveal expected answers before the attempt; transfer tests must not recycle the supplied worked solution. Factual source-comprehension displays the approved excerpt, while retrieval practice recalls a previously demonstrated idea. Neither arbitrary scores nor elapsed weeks certify competence.

Pilot first exposure, confusion mixed with a valid attempt, more-hints versus full-solution requests, stale state, missing provider access, regression and resume. Structural text checks do not prove tutoring effectiveness. Measure active time/setup/repair, hint use, learner independence and outcomes before making timing or mastery claims.
