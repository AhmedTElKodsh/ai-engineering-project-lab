# Explorations

The one sanctioned place for side quests: a tutorial you want to follow tonight, a library you want to poke at, a notebook from a video. Starting here instead of in a new repository keeps all learning in one place.

## Rules

- One folder per topic, named for the topic, with one line in the index below.
- No route, tutor, progress file or evidence. Explorations earn no stage credit; if one teaches something real, it re-enters through a route stage with a fresh case.
- Notebooks are committed with outputs cleared. Generated data, models, caches and `.env` files stay out of Git.
- Dependencies for an exploration live in that folder's own notes or requirements file; they are not added to the workbench environment.
- Do not commit copyrighted third-party text. Link to the source instead.
