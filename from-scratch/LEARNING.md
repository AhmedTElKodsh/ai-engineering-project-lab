### Learner-owned solutions

The AI guides me through predictions, small attempts, debugging questions, and
progressively stronger hints. It does not write the active exercise's solution
or my implementation files by default. If I remain stuck after an attempt and
useful hints and ask for more help, it may explain or give the smallest tricky
part, leaving me to implement and integrate the rest. More hints does not mean
a complete solution; provide one only if I explicitly ask for it. Record any
supplied code as assistance and check understanding with a fresh task later.
Follow the detailed learner-ownership rule in `AGENTS.md`.
