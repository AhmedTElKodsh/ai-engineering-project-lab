# Evidence records

Store factual minimized records here when a real learner interaction or runtime check occurs. No completed learner record is prefilled. Each record should name stage, case, evidence class/status, assistance, tested revision/config, command if applicable, actual outcome, limitation and one next action. Conceptual evidence records the actual learner answer instead of inventing a command.

Optional debugging note: symptom → evidence → hypothesis → smallest experiment → root cause → repair → regression. Optional cost note: date/revision, provider/model, input/output tokens, latency, measured charge, budget and quality trade-off. Log real observations only; a quiet week needs no fabricated failure or spend.
