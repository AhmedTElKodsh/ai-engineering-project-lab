# Resources shelf

Supporting material for the one route. Nothing here is a second course or awards stage credit.

| Path | Use |
|---|---|
| [corpora/hr-policy](corpora/hr-policy/README.md) | Fictional HR corpus and eval sets: selected extracts at S0–S2; full expansion from S3 |
| [extraction-fixtures](extraction-fixtures/README.md) | Structured-extraction challenge fixtures for S2 and Unicode practice |
| labs/ | Six plain-Python TODO labs (tokenization, vector search, attention, context/decoding, transformer block, gradient training) for the optional from-scratch track |
| [from-scratch-lessons](from-scratch-lessons/README.md) | Edited upstream lessons (tokenizer, mini-GPT, SFT, evaluation) for the optional from-scratch track |

The labs have no hidden completed solution. Their failing behavior checks are excluded from normal CI, while import/collection health is checked. Use one lab at a time. From-scratch lessons are neither collected nor linted here.
