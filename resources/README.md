# Focused mechanism shelf

Six retained plain-Python TODO labs provide tokenization, vector operations/search, attention, context/decoding, a transformer block and gradient training. They are supplementary inputs to the one S0–S8 route. No hidden completed solution is installed. Their initial failing behavior checks are excluded from normal repository CI, while import/collection health is checked separately. Use one lab at a time and return its learned operation to the cumulative project. No full model, learner completion or API currency is inferred from this shelf.
